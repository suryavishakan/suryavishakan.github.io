# Surya Vishakan – Portfolio

React 19 + Vite. Builds to a single `dist/index.html`.

## Run locally
    npm install
    npm run dev        # http://localhost:5173

## Build
    npm run build      # output in dist/
    npm run preview

## Edit content
All text, links, experience, skills and projects live in `src/content.js`.
Your photo cutout is `src/assets/me-cut.webp`; the resume is `src/assets/Surya_Vishakan_Resume.pdf`.

## Deploy (Netlify)
Build command `npm run build`, publish directory `dist` (already set in `netlify.toml`).
